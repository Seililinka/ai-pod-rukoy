# AI под рукой

Промпты для жизни и работы: **422 полных английских текста**, **402 задачи**, **11 тем**.

Русские описания помогают выбрать подходящий промпт. В книге есть поиск, переходы по темам, раскрытие полного английского текста и копирование.

Для ответов на русском добавьте к выбранному промпту: **«Говори на русском»**.

## Публикация книги

В настройках репозитория откройте **Settings → Pages**. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**. После публикации GitHub покажет ссылку на книгу.

Весь текст и оформление включены в `index.html`; установка пакетов и отдельный сервер не требуются.

Источник английских промптов — [There’s An AI For That](https://theresanaiforthat.com/). Ссылки на источники сохранены в карточках книги.

## Счётчик просмотров

Внизу опубликованной книги расположен общий счётчик [Hits.sh](https://github.com/silentsoft/hits). Нажатие на значок открывает статистику по дням. Учёт начат 3 ноября 2026 года: считаются открытия страницы, в том числе повторные и технические проверки, а не уникальные читатели. История до подключения счётчика не восстанавливается.

Счётчик работает только на GitHub Pages этой книги. Поиск, раскрытие промптов и переходы по темам не добавляют просмотры. Фиксированный адрес запроса не содержит текстов промптов, поисковых запросов, параметров страницы или её referrer; cookies и идентификаторы пользователя не добавляются. При недоступности счётчика книга продолжает работать.
